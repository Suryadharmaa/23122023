# Spotify di Memory Desktop

Jendela Spotify di Dock memakai [Spotify Embed resmi](https://developer.spotify.com/documentation/embeds). Tidak perlu akun Developer, Client ID, atau konfigurasi GitHub Pages.

1. Buka lagu, album, playlist, artis, atau podcast di Spotify.
2. Pilih **Bagikan → Salin tautan**.
3. Buka aplikasi **Spotify** di Dock Memory Desktop, tempel tautan, lalu pilih **Tambah**.
4. Putar konten di pemutar Spotify yang muncul. Tautan tersimpan di browser yang dipakai.

Tautan `https://open.spotify.com/...`, Spotify URI, dan kode iframe embed resmi dapat ditempel. Untuk memakai akun Spotify biasa, ikuti tombol login yang ditampilkan Spotify di pemutarnya jika ada, atau gunakan tombol **Buka Spotify**. Proses login dan sesi berada di Spotify. Aplikasi ini tidak meminta atau menyimpan kata sandi Spotify.

Spotify menentukan apakah pemutar embed dapat memutar lagu penuh atau hanya cuplikan. Browser dan kondisi akun juga memengaruhi hasilnya. [Panduan pemecahan masalah Spotify Embed](https://developer.spotify.com/documentation/embeds/tutorials/troubleshooting).
